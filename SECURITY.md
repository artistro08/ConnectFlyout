# Security Policy

## Reporting a Vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub's [private vulnerability reporting](https://github.com/artistro08/ConnectFlyout/security/advisories/new) instead.

Include what you found, the steps to reproduce it, and the ConnectFlyout version you're running. You'll get a reply as soon as possible, and a fix will ship in the next release.

## Supported Versions

Only the latest release gets security fixes.
